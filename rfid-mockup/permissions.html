Permission model

How roles map to console areas in this mockup (intended to mirror server-side RBAC and API scopes).

Admin has full access including user lifecycle and machine registry actions. Operator focuses on fleet health and transaction logs. Staff uses read-only reporting paths. Navigation and page gates are enforced in the browser for demonstration only.
