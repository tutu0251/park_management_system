Status checks & filters

Status protocol (server ↔ machine)

Machines do not send “New” or “Added”. The operations UI derives New when reader_id / game_id / node_id is unknown in the database, and Unknown type when type_id is unknown.

Server → machine / reader

  • node_id, reader_id, game_id, type_id, event_type=CheckStatus

Machine / reader → server

  • … event_type=Online
  • … event_type=Maintenance
  • … event_type=Offline
  • … event_type=Error

UI mapping: node_id → location · type_id → cost · offline machines may be removed from the park → Remove hides them from the active list (history kept).
